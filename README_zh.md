# 内言语自主触发基准

这个仓库把侵入式内言语解码拆成两个不能混为一谈的问题：

1. **事件对齐的内容分类：** 已知一次提示表达何时开始后，接下来 250、500 或 1000 ms 能否区分七个词？
2. **自主输出：** 不把试次边界告诉触发器时，同一组简单模型能否决定何时输出，同时控制错词、漏检、误触发和重复输出？

解码算法本身并不新：模型是收缩 LDA 和对角协方差 LDA，流式部分是滑窗加有限状态触发规则。可取之处在于严格而可复现的**评估协议**，尤其是不把“已经切好的提示试次分类正确”写成“有个念头即可输出”。

## 核心结果

Stanford `interleavedVerbalBehaviors` 数据的前向留出记录块中，500 ms 七词内言语分类的机会水平为 14.3%。收缩 LDA 结果为：

| 参与者 | 准确率 | 正确数 / 测试数 |
|---|---:|---:|
| T12 | 32.1% | 9 / 28 |
| T15 | 30.0% | 21 / 70 |
| T16 | **78.6%** | **22 / 28** |
| T17 | 32.9% | 23 / 70 |

T16 的两个测试块各为 11/14，说明至少有一位参与者在半秒内存在很强的有限词身份信息。其余三人的表现明显较低，不能概括成普遍的快速准确解码。

预先固定的流式规则没有任何非静默门限同时满足验证约束，最终选择了明确的静默候选。两个模型都漏掉全部 196 个测试内言语试次。仓库把它报告为失败，不会把“没有误输出”包装成成功。

## 这个 benchmark 的价值

- 按记录先后留出完整块，避免随机拆分相邻试次造成过度乐观；
- 训练、验证和测试职责分开，测试结果不参与门限选择；
- 只用当前时点以前的已发布分箱，不做测试块整体中心化或对称平滑；
- 分开报告内容可解码性与连续自主控制；
- 全部错词、漏检、重复和非目标暴露都进入结果；
- 保留静默策略，但静默只能判作无效系统；
- 报告每位参与者和每个测试块，不用总体平均掩盖异质性。

因此，合适的公开定位是“内言语 BCI 的可复现评估基准／方法案例”，而不是“新型解码算法”或“新的神经机制发现”。详细边界见 [新颖性与主张范围](docs/NOVELTY_AND_SCOPE.md)。

## 数据与复现

仓库不包含原始神经数据。请从官方 [Dryad 页面](https://datadryad.org/dataset/doi:10.5061/dryad.gf1vhhn1j)下载 `interleavedVerbalBehaviors.zip` 并在本地解压。预期大小为 `777419058` bytes，SHA-256 为 `19f90f09f2ea32f1428b7cc1c7dd8c0606dfbc988c57fcaf64aea03e77b9d409`。

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e '.[test]'

inner-speech-benchmark \
  --data-dir /path/to/interleavedVerbalBehaviors \
  --output-dir reproduced_results

inner-speech-report \
  --output-dir reproduced_results \
  --figure-dir reproduced_figures

pytest
```

运行不需要任何 API，不会调用外部模型服务。

## Jev 在本项目中的真实作用

[Jev](https://docs.typesafe.ai/introduction) 只在神经数据分析之前的独立合成交互实验中作为结构化语义先验接受过评估。在上下文与隐藏目标一致时，Jev 方案减少了模拟输入次数；但相对简单方法的收益没有达到预设继续投入门槛，也没有表现出相对快速通用 LLM 的独特优势。上下文无信息或与目标相反时，性能明显下降。

因此 Jev 没有进入本仓库的神经特征、分类器、门限选择或测试评价，任何神经数据都没有发送给 TypeSafe 或其他模型提供商。这里说明“用过 Jev”是为了完整披露研发路线，而不是暗示 Jev 提高了神经解码。聚合结果见 [Jev 评估说明](docs/JEV_EVALUATION.md)。

仓库作者与维护者为 GitHub 用户 [Dililianxice](https://github.com/Dililianxice)。代码、说明和图按 MIT 许可发布；派生 CSV/JSON 表按 CC0 1.0 发布。使用时仍应按学术规范引用原始 Cell 论文、Dryad 数据和本仓库，详见英文 README 与 `CITATION.cff`。

## 解释限制

本任务的词由提示给出，阶段起点也已知；神经特征可能同时包含提示记忆、准备和内言语执行。相对 GO 的延迟不能叫作思想起点。每人只有一天数据，do-nothing 测试只有 4–5 个试次，不能据此声称跨日稳定、日常误触发率很低或可读取任意私密思想。
