# Jev × 内言语 BCI

## 少一点神经输入，能不能完成更多事情？

这个项目不是从“再造一个更大的解码器”开始的，而是从一个很实际的问题开始：

> 如果未来的 BCI 每次只能可靠地给出少量、带噪声的意图线索，能不能用快速的语义模型把这些线索变成有用的行动，同时不假装从大脑里读出了更多信息？

这让我们注意到 [Jev](https://docs.typesafe.ai/introduction)。Jev 是 TypeSafe 面向结构化判断的 System One 模型，可以直接返回选择、概率和置信度。它很适合充当 BCI 的“语义先验”：应用场景提出可能目标，神经信号负责表达用户自己的选择，普通代码再决定证据是否足以行动。

我们先测试了这个想法最吸引人的部分。在独立的合成交互任务里，当上下文确实与目标有关时，Jev 能减少模拟用户输入。然后我们测试了更难、也更关键的部分：公开侵入式内言语数据能不能提供一次快速而可靠的自主表达事件。

结果不是一个整齐的成功故事，但更有研究价值：

- **Jev 显示出输入效率信号：** 三个槽位全部完成的成功率为 94.2%，平均需要 6.507 次输入；本地 embedding 基线为 96.0% 和 8.043 次输入。
- **这个收益并非 Jev 独有：** 匹配的快速通用 LLM 达到 94.2% 和 6.128 次输入。
- **一位参与者的短窗神经内容很强：** T16 使用 500 ms 数据进行七词分类达到 78.6%。
- **“何时输出”仍没有解决：** 所有非静默策略都违反冻结的验证约束，唯一合格的策略保持静默并漏掉全部测试表达。

这个仓库把四件事放在一起。Jev 是推动我们思考交互层设计的起点；神经 benchmark 则明确指出，这个想法目前缺少什么样的可靠控制信号。

## 为什么 Jev 值得放进未来 BCI 的讨论

许多语言模型集成先生成文字，再让程序解析。Jev 直接给出结构化判断，更容易被明确的工程规则组合：

```text
神经证据  +  Jev 语义先验  +  明确的决策规则
 用户选什么      哪个目标更可能       证据够不够行动
```

在合成实验中，Jev atomic 相对本地 embedding 基线减少了 19.1% 的输入，成功率下降 1.83 个百分点。以六个独立测试主题为重采样单位的配对 cluster bootstrap 给出探索性 95% 区间：输入减少 3.7%–30.5%，成功率差 −3.50–0.00 个百分点。

它的帮助依赖上下文确实有信息。当建议与隐藏目标无关时，Jev atomic 成功率降到 87.3%；建议与目标相反时降到 83.7%。完整的脱敏聚合数据见 [`results/jev_synthetic_pilot_summary.csv`](results/jev_synthetic_pilot_summary.csv)，解释见 [Jev 评估说明](docs/JEV_EVALUATION.md)。

Jev **没有**参与神经特征提取、分类器拟合、测试结果调参或参与者数据处理。神经数据没有发送给 TypeSafe 或其他模型服务。语义先验可以减少交互，但不能创造没有从神经信号中解码出来的信息。

## 神经 benchmark 真正测什么

我们把两个经常被混在一起的问题分开：

1. **事件对齐的内容分类：** 已知提示表达何时开始后，接下来 250、500 或 1000 ms 能否区分七个词？
2. **自主输出：** 不把试次边界告诉触发器时，模型能否自己决定何时输出，同时控制整段记录中的误触发和重复输出？

Stanford `interleavedVerbalBehaviors` 数据的前向留出记录块中，500 ms 收缩 LDA 七词分类结果如下，机会水平为 14.3%：

| 参与者 | 准确率 | 正确数 / 测试数 |
|---|---:|---:|
| T12 | 32.1% | 9 / 28 |
| T15 | 30.0% | 21 / 70 |
| T16 | **78.6%** | **22 / 28** |
| T17 | 32.9% | 23 / 70 |

T16 的两个测试块各为 11/14，说明至少有一位参与者在半秒内存在很强的有限词身份信息。其余三人的表现明显较低，不能概括成普遍的快速准确解码。

预先固定的流式规则没有任何非静默门限同时满足验证约束。最终策略没有输出，两个模型各漏掉全部 196 个内言语测试试次。仓库把它报告为失败，不会把静默带来的“零误输出”包装成成功。

## 这个 benchmark 的价值

模型本身是标准的收缩 LDA 和对角协方差 LDA。主要贡献是严格而可复现的评估协议：

- 按记录先后留出完整块，避免随机拆分相邻试次；
- 训练、验证和测试职责分开；
- 不做测试块整体中心化或对称时间平滑；
- 分开报告“内容可解码”和“连续自主控制”；
- 把 imagined GO 之外的全部记录时间纳入误输出暴露；
- 保留所有错词、漏检、重复和负结果；
- 允许静默候选，但静默只能判作无效接口；
- 报告每位参与者和每个测试块，不用总体均值掩盖异质性。

合适的定位是“内言语 BCI 的可复现评估基准和方法案例”，不是一种新型神经解码器，也不是新的神经机制发现。

## 数据与复现

仓库不包含原始神经数据。请从官方 [Dryad 页面](https://datadryad.org/dataset/doi:10.5061/dryad.gf1vhhn1j)下载 `interleavedVerbalBehaviors.zip`。预期大小为 `777419058` bytes，SHA-256 为 `19f90f09f2ea32f1428b7cc1c7dd8c0606dfbc988c57fcaf64aea03e77b9d409`。

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e '.[test]'

inner-speech-benchmark \
  --data-dir /path/to/interleavedVerbalBehaviors \
  --output-dir reproduced_results

inner-speech-report \
  --output-dir reproduced_results \
  --figure-dir reproduced_figures

pytest
```

神经 benchmark 不需要任何 API，也不会调用外部模型服务。

## 解释边界

任务词和阶段起点都由提示给出，神经特征可能同时包含提示记忆、准备和内言语执行。相对 GO 的延迟不是私密思想的起点。每人只有一天数据，do-nothing 测试只有 4–5 个试次，不能据此声称跨日稳定、日常使用安全或读取任意思想。
