# Reproducibility record

The final public package was rebuilt from the official four extracted MAT files using the command below. Every generated JSON/CSV artifact listed below matched the committed version byte-for-byte. `manifest.json` stores the SHA-256 of each source MAT file, the complete frozen configuration, and the benchmark-code hash. `COMPLETED.json` records the completed participants, manifest hash, and expected metric-row count.

```bash
PYTHONPATH=src python -m inner_speech_benchmark \
  --data-dir /path/to/interleavedVerbalBehaviors \
  --output-dir /tmp/inner-speech-reproduction

PYTHONPATH=src python -m inner_speech_benchmark.report \
  --output-dir /tmp/inner-speech-reproduction \
  --figure-dir /tmp/inner-speech-reproduction-figures
```

The Jev synthetic-pilot aggregate is a sanitized historical disclosure and is not generated by the neural benchmark runner. `runtime_environment.json` records Python, package, platform, BLAS, and thread settings; `requirements-lock.txt` pins the Python packages used for the release. `CHECKSUMS.sha256` covers all committed result tables, provenance files, figures, and runtime records. PNG/PDF rendering can vary across Matplotlib and font-library versions even when source CSV files are identical.
